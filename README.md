# Date my friend, by Mawuna

Invitations à des friendship dates : billet, tirage de cartes, créneaux, billet final avec mot doux.

## Mettre en ligne (une seule fois)

1. **GitHub** : crée un nouveau dépôt (par exemple `date-my-friend`), puis *Add file > Upload files* et dépose `index.html` et ce `README.md`. Valide avec *Commit changes*.
2. **Vercel** : *Add New > Project*, importe le dépôt `date-my-friend`, laisse tous les réglages par défaut (pas de framework, pas de build) et clique sur *Deploy*.
3. Vercel te donne une adresse du type `https://date-my-friend.vercel.app`.

## Envoyer une invitation

Le lien d'une pote = l'adresse Vercel + `#son-prénom`, par exemple :
`https://date-my-friend.vercel.app/#segolene`

Sans `#prénom`, la page affiche seulement un mot d'accueil : l'admin n'est jamais visible en ligne.

## Modifier ou créer des invitations

1. Ouvre `index.html` **sur ton ordinateur** (double-clic, dans Chrome) : tu arrives sur ton admin.
2. La première fois, dans *Réglages*, colle ton adresse Vercel et ton numéro WhatsApp.
3. Fais tes changements puis *Enregistrer* : Chrome télécharge un nouveau `date-my-friend.html`.
4. Renomme-le en `index.html` et remplace l'ancien dans le dépôt GitHub (*Add file > Upload files*). Vercel met le site à jour tout seul en quelques secondes.
